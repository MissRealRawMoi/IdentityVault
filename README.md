# IdentityVault
Identity Vault is designed to protect &amp; manage users' digital identities. It leverages biometric authentication, such as fingerprint/iris recognition, to provide an additional layer of security, insuring that only authorized users can access sensitive information stored securely.
# IdentityVault

IdentityVault is a biometric identity verification and social account recovery system.  
It allows users to verify themselves using their fingerprint and legal name, then automatically regain access to linked social media accounts.

---

## Features
- Fingerprint-based identity verification
- Secure name + identity matching
- OAuth-powered social account recovery
- Zero biometric storage
- Temporary access tokens

---

## Project Structure
- **backend/** — Node.js API for verification + recovery
- **mobile/** — React Native app for fingerprint + identity input
- **database/** — SQL schema for identity storage
- **identityvault_spec.md** — System design document
