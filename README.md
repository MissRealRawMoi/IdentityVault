# IdentityVault

IdentityVault is a biometric‑anchored identity verification and account recovery protocol.  
It provides secure, cross‑platform account restoration, optional verified compute contribution,  
and a legally separated utility token (IVT) that does not represent ownership or governance.

## Documentation

All formal documentation is located in the `/docs` directory:

👉 [IdentityVault Documentation Index](docs/README.md)

## Features

- Biometric identity verification (no raw biometric storage)
- Secure multi‑platform account recovery
- Verified Human Compute Network (optional)
- Non‑Ethereum IVT utility token
- Legal separation between token and ownership
- Full technical, legal, and business documentation in `/docs`

## Getting Started

### Backend
Node.js / Express API for identity verification, recovery flows, and compute coordination.

### Mobile App
React Native client for biometric capture, identity submission, and recovery dashboard.

### Database
PostgreSQL or MySQL storing hashed biometric templates, linked accounts, and recovery tokens.
